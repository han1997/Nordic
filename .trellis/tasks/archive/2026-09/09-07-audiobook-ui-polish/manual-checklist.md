## 书籍详情头部

- [ ] 竖屏普通宽度：封面在左、文字在右（并列布局），封面 128dp。
- [ ] 720dp 宽屏 / 横屏：封面 160dp，文字区更宽。
- [ ] 系统最大字体：概览切换为上下堆叠并水平居中，标题/副标题/操作按钮均不截断。
- [ ] 长书名最多三行，超出省略；续播 chip 与章节/时长 chip 同行排列，放不下自动换行。
- [ ] 「继续播放」按钮宽度受限（最长 360dp），不会撑满整行。

## 简介

- [ ] 超过三行的简介截断显示「展开简介」按钮；点击展开全文，再点「收起简介」。
- [ ] 短简介（三行内）不显示展开按钮。
- [ ] 切换到另一本书再回来，展开状态不串（按书隔离）。
- [ ] 无简介的书不显示简介卡片。

## 缺省文案

- [ ] 作者缺失的书：列表卡、详情页、页头副标题均显示「未知作者」，不再隐藏该行。
- [ ] 「章节」节头颜色与其他节头一致（浅色深灰、深色浅灰）。

## 回归确认

- [ ] 章节面板、书签面板、定时面板、倍速面板样式与上一批一致。
- [ ] 书签行选中态副标题在浅色/深色下均清晰可读。
- [ ] 库切换、刷新、配置切换后页面状态正常。
- [ ] 浅色 / 深色主题均检查一次；竖屏与横屏均检查一次。
