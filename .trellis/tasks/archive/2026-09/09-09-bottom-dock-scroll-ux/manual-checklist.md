# 底部导航 Dock 滚动交互优化：真机验收清单

前置：任一媒体域有可滚动列表（音乐/有声书/视频首页均可）。

## 阈值防误触（A）

- [ ] 手指轻碰/微滚（<24dp）→ dock 不消失。
- [ ] 正常滚动一屏 → dock 收起，只剩把手。
- [ ] 滚动中途反向（下-上-下小幅晃动）→ 不触发隐藏（方向反转复位）。

## 向上滚恢复（B）

- [ ] dock 收起后，手指下拉（向上看内容）滚动一屏 → dock 自动恢复。
- [ ] 轻拉（<24dp）→ 不恢复。
- [ ] dock 可见时向上滚 → 无任何变化。

## 到底恢复（C）

- [ ] 列表滚动到底部（到底 overscroll）→ dock 自动恢复。
- [ ] 恢复后内容底部不被遮挡（padding 动画正常）。

## 把手触达（D）

- [ ] 把手视觉尺寸不变（小胶囊），但点击区域明显更大（≥48dp 高），单手易点中。
- [ ] 无障碍扫描（TalkBack）可聚焦并激活把手。

## 回归

- [ ] 播放器（音乐/有声书/视频）打开时 dock 完全隐藏。
- [ ] 切 tab → dock 恢复显示。
- [ ] 收起后点把手 → dock 恢复。
- [ ] dock 收起/恢复动画流畅（260/150ms），内容 padding 无跳变。
