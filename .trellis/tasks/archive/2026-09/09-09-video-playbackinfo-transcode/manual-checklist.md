# 视频 PlaybackInfo 转码与清晰度选择：真机验收清单

前置：Emby 服务器 4.9+（验证用 4.9.5.0），媒体库含直连可播与需转码的视频（如 4K H.265）。

## 清晰度选择

- [ ] 设置面板出现「清晰度」行，摘要显示当前档位（默认「自动」）。
- [ ] 打开清晰度面板：6 档（自动/原始/2M/4M/8M/20M），当前档高亮，每档有说明副标题。
- [ ] 切换档位后重启应用，档位保持。
- [ ] 切换档位不中断当前播放；重新播放后新档位生效。

## 转码播放

- [ ] 选 4M 档播放 4K/H.265 视频 → 服务器转码（H.264/AAC HLS），可正常播放、seek、暂停。
- [ ] 转码播放时关闭播放器 → Emby 后台会话正常结束（控制台可见 Stopped 带 PlaySessionId）。
- [ ] 转码播放中进度上报正常（详情页续播点跟随）。
- [ ] 选「原始」档 → 直连播放（行为与旧版本一致）。
- [ ] 选「自动」档 → 直连优先，无握手请求。

## 回退

- [ ] 转码流播放失败（可模拟：暂停服务器转码服务）→ 自动回退直连重试一次，进度保留。
- [ ] 回退后仍失败 → 显示「视频播放失败」错误卡，可关闭。

## 回归

- [ ] AUTO 档直连播放、进度上报、章节跳转、片头跳过、画中画均不回归。
- [ ] 音乐/有声书不受影响。
