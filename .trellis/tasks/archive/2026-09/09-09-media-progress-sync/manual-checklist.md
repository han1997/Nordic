# 媒体进度与播放状态同步补全：真机验收清单

前置：Navidrome + AudiobookShelf 服务器可访问。

## 音乐 scrobble（Navidrome）

- [ ] 完整播放一首歌（超过一半）→ Navidrome 网页端「最近播放」出现该曲、播放次数 +1。
- [ ] 播放一首歌几秒后切下一首 → 前一首在「最近播放」出现（切歌触发提交）。
- [ ] 同一首歌播放过半后拖回重听、再次过半 → 播放次数只 +1（不重复提交）。
- [ ] 播放中断网 → 无错误弹窗，播放正常；恢复网络后下一首 scrobble 恢复。
- [ ] 未配置 Navidrome 时播放本地/无服务器歌曲 → 不崩溃、无请求。

## 有声书 ON_STOP 安全网（AudiobookShelf）

- [ ] 有声书播放中按 Home 回桌面 → 立即查看 ABS 网页端进度为当前播放位置（而非 30s 前的旧位置）。
- [ ] 回桌面后播放继续（不中断）。
- [ ] 回到应用继续播放 → 进度连续无回跳。
