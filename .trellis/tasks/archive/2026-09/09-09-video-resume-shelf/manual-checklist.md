# 继续观看对齐服务器 Resume 列表：真机验收清单

前置：Emby 服务器可访问；最好有第二台设备（或网页端）产生过观看进度。

## 对齐验证

- [ ] 在 Emby 网页端看一段视频（几秒即可）→ App 视频首页「继续观看」出现该条目（旧版本本地推导也会显示，但需确认服务器列表条目与网页端一致）。
- [ ] 在网页端把某视频标记为已看完 → App「继续观看」不再显示该条目（服务器规则隐藏接近看完的内容）。
- [ ] 在另一设备观看某视频 → App 刷新后「继续观看」显示该条目及正确进度（无需等 30 分钟目录缓存）。
- [ ] App 内播放几秒后关闭 → 「继续观看」进度与服务器一致。
- [ ] 「继续观看」卡片点击可正常播放并从服务器进度续播。

## 回退验证

- [ ] 断网打开视频页（有缓存）→ 「继续观看」仍显示（本地推导回退），无错误弹窗。
- [ ] 恢复网络刷新 → 列表回到服务器版本。

## 回归

- [ ] 「最高评分」「未观看」shelf 不回归（仍本地推导）。
- [ ] 媒体库切换、搜索、类型筛选不回归。
- [ ] 视频播放、进度上报、章节/片头/清晰度/画中画不回归。
