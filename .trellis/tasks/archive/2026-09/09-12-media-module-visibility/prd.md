# 媒体模块显示开关与设置导航优化

## 已确认目标

- 音乐、有声书、视频可分别显示/隐藏，默认全部显示，至少保留一个。
- 设置移出底部导航，各媒体首页固定齿轮入口；未配置、加载、错误状态也可进入。
- 两个/三个模块时显示媒体导航；一个模块时不显示导航、空占位和无意义把手。正在播放条独立保留；设置页面没有媒体导航。
- 隐藏模块时隐藏专属播放设置及对应搜索项；服务器、存储、隐私与功能展示入口不受影响，数据与下载任务保留。
- 隐藏正在播放/暂停/准备中的模块需确认，按现有进度关闭策略停止该模块；取消准备与视频连播，不能误停另一类音频。
- 关闭或偏好提交失败保持模块可见；已停止的播放不自动重启。隐藏模块不能从下载/迟到回调重新开播。
- 启动页与上次媒体页只指向可见模块，隐藏后按音乐→有声书→视频回退；重新显示不自动切页/播放，设置页面不因切换可见性被退出。
- 设置独立导航：齿轮到首页、管理服务器直达服务器；返回搜索/子页/原媒体，保留未保存草稿保护。

## 实施约束

- 三个布尔字段加入 AppPreferences，旧配置缺省 true，异常全关读取恢复全部显示，写入拒绝全关；不改缓存 schema、认证或数据归属。
- 复用 data.MediaDomain 的稳定身份和原 0/1/2 映射，不使用过滤后下标作为导航标识。
- 复用现有共享 UI、HeaderAction、48dp 触控与主题；固定齿轮预留位置，其他操作在窄屏溢出。
- 复用共享媒体交接门闩与关闭回调；音乐/有声书共享服务，停止仅对所属域生效。
- 有声书启动增加可取消请求和迟到隔离；各播放入口/准备完成时校验模块可见性。

- [ ] 独立设置入口、分类/搜索过滤、单模块底栏与迷你播放器、返回及草稿保护。
- [ ] 三域播放/准备中隐藏、失败/取消/迟到响应、共享服务互不误停、隐藏音乐下载播放限制。
- [ ] 编译、全量单测、Lint、Debug/Release 打包、APK 身份/签名与 Release Retrofit 泛型核验。
- [ ] README、CHANGELOG、相关规范与验收记录同步，版本 0.1.7 / 7。

## 范围边界

不删除服务器、历史、下载，不取消已有下载，不重做全应用视觉，不新增服务协议或依赖。
