# 视频章节跳转与片头跳过：真机验收清单

前置：Emby 服务器 4.9+（验证用 4.9.5.0），媒体库含带章节/片头 marker 的剧集与只有普通章节的电影。

## 章节跳转

- [ ] 播放带章节的剧集 → 设置面板出现「章节」入口行，摘要显示「N/M · 当前章节名」。
- [ ] 打开章节面板：当前章节高亮（primaryContainer 背景 + 勾选），列表按时间排序。
- [ ] 点击任一章节 → 面板关闭，播放跳转到该章节起点。
- [ ] 播放无章节的视频 → 设置面板不显示章节入口。
- [ ] 大字体（fontScale 1.5/2）下章节行文字完整、触达 ≥ 56dp。

## 片头跳过

- [ ] 播放带 intro marker 的剧集 → 进入片头区间时出现「跳过片头」浮动按钮（右下角）。
- [ ] 点击按钮 → 跳到片尾 marker 位置（正片开始），按钮消失。
- [ ] 自动跳过开启（默认）时：不点按钮，播放进入区间自动跳一次，之后不再重复跳。
- [ ] seek 回片头区间内 → 不再自动跳（once 语义），手动按钮仍可用。
- [ ] 设置面板「自动跳过片头」开关可切换；关闭后重启应用仍为关闭，自动跳过不再发生，手动按钮仍可用。
- [ ] 播放无 intro 数据的视频 → 无开关行、无按钮。
- [ ] PiP 小窗内不显示跳过按钮与任何面板。
- [ ] 手势锁定时按钮隐藏；错误/缓冲状态卡显示时按钮隐藏。

## 回归

- [ ] 章节跳转后进度上报正常（30s 周期 + 关闭时 Stopped）。
- [ ] 片头自动跳过后的位置被 Emby 记录（关闭播放器后详情页续播点在正片）。
- [ ] 音乐/有声书播放不受影响。
- [ ] 画中画行为不回归（进入/展开/关窗即停）。
