# Media App UI Reference

## Sources

* Spotify Android now-playing screenshots: large centered play/pause action, simple linear transport icons, sparse active accent color.
* Plexamp Android screenshots: album-art-driven color atmosphere, compact transport controls, persistent bottom player with artwork and play action.
* Symfonium / Subsonic-style player screenshots: blurred album artwork used as a background layer, with controls on readable translucent panels.

## Takeaways For Nordic

* Replace text-glyph controls with consistent Material icon vectors where lucide-equivalent Material icons already exist in the Android stack.
* Keep the primary play/pause button as the dominant control. Secondary actions should stay tonal/ghost and visually quieter.
* Use glass/frosted treatment selectively on persistent chrome and player surfaces, not on every list row or card.
* Let album art / cover art drive perceived depth where possible. Avoid generic decorative blur layers that compete with media content.
* Preserve strong contrast and stable touch targets; blur is decoration only when readability remains intact.

## Candidate Nordic Targets

* Header action buttons: replace text symbols for refresh/theme/back with vector icons.
* Bottom navigation: replace text symbols for Music/Audiobook/Video/Config with vector icons.
* Playback dock: replace text play/pause glyphs with vector icons and consider a subtle glass overlay.
* Search and queue actions: use vector icons where controls are currently text-like symbols.
