# UI 第十二轮:真实服务器联测验收

## Goal

在前十一轮纯样板/模拟验证后,用真实自托管服务器在专用模拟器上做一轮按域的联测:登录连接、库浏览、播放启动/暂停/续播、进度同步与返回续播。本轮不改生产代码(除非发现阻塞性 UI 缺陷需记录),只产出按域的真实联测记录与设备截图证据,补足前几轮 spec 反复标注「真实服务器验收未验证」的部分。

基线为 `main / a451eec`,版本维持 `0.1.19 / 19`(纯验收轮,不升版本)。沿用专用 AVD `nordic-ui-api34 / emulator-5580`,不操作个人设备。服务器凭证由用户手工输入应用设置并仅驻留模拟器加密存储,不写入本仓库任何文件;截图只覆盖 Home/详情/播放器,不拍设置表单。

## Requirements

- 安装当前 Release 0.1.19(或等值 Debug)到专用模拟器;用户手工在 Nordic 设置中输入四类服务器:
  Navidrome / AudiobookShelf / Emby / WebDAV(视频域),各填地址、用户名与密码;凭证仅存模拟器本地,不进入仓库。
- 逐域验收并记录:
  - 音乐:Navidrome 登录、首页发现/最近播放、专辑/歌手/歌单浏览、单曲播放、暂停/恢复、进度恢复、歌词加载(若有)、收藏切换(若允许)。
  - 有声书:AudiobookShelf 登录、书库/条目浏览、播放、章节跳转、书签增删、进度恢复、睡眠定时设置。
  - 视频(Emby/WebDAV):登录、媒体库/网盘目录浏览、播放/暂停/续播、WebDAV 目录导航与文件信息。
  - 各域返回续播与实际进度上报行为以真实服务为准,与媒体库实际内容一致。
- 对发现的 UI 缺陷(排版/裁切/状态误导)只记录 `r12-*` 证据与结论,不改代码;是否后续修复由用户决定。
- 设备截图只含 Home/详情/播放器画面,不含设置表单或任何凭证明文;证据按域分批命名存入 `app/build/reports/ui-polish/r12/` 与任务 `research/`。
- 若服务器不可达或凭证无效,如实记录失败,不以模拟样板替代真实结果。

## Acceptance Criteria

- [ ] 四类服务器均在专用模拟器完成登录连接(或如实记录连接失败及原因)。
- [ ] 音乐/有声书/视频(Emby+WebDAV)各自完成一次真实播放闭环(启动→暂停/恢复→进度),并按域产出证据。
- [ ] 所有截图与记录不含凭证明文;仓库无任何新增凭证落盘。
- [ ] Release 签名/manifest/DEX 合同检查通过(若重新构建)。
- [ ] 未验证项如实记录,不宣称已验收。

## Definition of Done

- 更新必要的联测记录到任务 `research/`,完成 `trellis-check`、单次确认提交和任务归档。
- 本轮不涉及 spec 变更(无新约定);若发现需文档化的真埋点,另起轮次。

## Technical Approach

安装 Release/已知构建 → 用户手工输入服务器 → 逐域通过 adb 截图 + 交互走 Print 集证据 → 端口侧写逐域记录到 `research/live-verification-r12.md`。全流程复用专用模拟器与 UiTest 设备常量,不改动生产源码。

## Decision (ADR-lite)

**Context**: 前十一轮 UI 验收均在 Debug 样板与模拟数据上完成,真实服务器行为未验。

**Decision**: 本轮为纯验收轮:真实服务器手动接入 + 按域联测 + 证据落 ATP 任务目录;发现缺陷不影响本轮完成,是否修复由用户定。

**Consequences**: 真实播放/进度/歌词等行为获得人工验收证据;不引入生产代码变更风险。

## Out of Scope

- 生产代码修改、无障碍工作(项目已明确不再投入)、版本号变更。
- 真实移动设备测试、云端/公网服务。

## Technical Notes

- AVD:`nordic-ui-api34` / `emulator-5580`;ADB 命令一律 `-s emulator-5580`。
- 凭证:仅有用户手工输入,不写入仓库文件;模拟器数据驻留本地存储。
- 输出:任务 `research/live-verification-r12.md` + `research/r12/` 截图批次。
